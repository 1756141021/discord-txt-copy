# Discord TXT 一鍵複製

這是給 Discord 網頁版用的 Chrome / Edge 擴充功能。聊天裡每個 txt 附件的檔名旁邊會多一顆「複製」按鈕，點一下就會把檔案內容複製到剪貼簿，不用先下載再打開。

檔案內容只會讀進記憶體，不會下載到電腦，也不會寫進瀏覽器的磁碟快取。除了 `.txt`，`.md`、`.log`、`.json`、`.csv` 也可以直接複製。編碼方面支援 UTF-8（含 BOM）、UTF-16 和 GBK/GB18030，Big5 編碼的檔案可能會變成亂碼。

## 安裝

1. 在本頁按綠色的「Code」→「Download ZIP」，下載後解壓縮。
2. 在 Chrome 網址列輸入 `chrome://extensions`（Edge 輸入 `edge://extensions`）。
3. 打開右上角的「開發人員模式」，按「載入未封裝項目」，選擇剛剛解壓縮出來、裡面有 `manifest.json` 的那個資料夾。
4. 重新整理 Discord 分頁。

Chrome 啟動時如果跳出提示，問你要不要停用開發人員模式的擴充功能，按保留就可以繼續使用。

## 使用

- 滑鼠移到按鈕上時會先開始讀取檔案，點下去通常就能馬上複製完成。
- 複製成功後，按鈕會變成綠色並顯示字數；失敗時會變成紅色，把滑鼠移上去就能看到錯誤原因。

這個擴充功能只能在瀏覽器開的 discord.com 上使用，Discord 桌面版 App 不支援。
